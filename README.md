# Q.ANT Native Computing Toolkit – Example Collection
Welcome! This repository contains a curated set of examples demonstrating how to use the Q.ANT Native Computing Toolkit for developing applications powered by the NPU.

## Overview
These examples are designed to help you get started quickly, whether you prefer working in Python or C++. Explore hands-on code samples that showcase common workflows and best practices with the toolkit.

## Prerequisites
Before running any examples, please ensure you have installed the appropriate Q.ANT Native Computing Toolkit interface:

Python API (provided as a Python wheel file): Required for Python examples

C++ API (provided as a installer): Required for C++ examples

Note: Without the corresponding API installed, the examples will not run.

## Directory Structure
cpp/ — Contains all examples using the C++ API

python/ — Contains all examples using the Python API

## Getting Started
Install the required API for your preferred language.

Navigate to the relevant subfolder (cpp/ or python/).

Follow the instructions in each example’s README or comments to run the code.
