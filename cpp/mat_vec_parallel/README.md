# Matrix-Vector multiplication on multiple NPUs 
This project demonstrates how to use get_available_npus() to parallelise workloads on multiple devices.

## Prerequisites
Q.ANT Native Computing Toolkit (NPU driver/API)

C++23-compatible compiler (GCC/Clang)

CMake >= 3.16

XTensor == 0.25.0

XTensor-BLAS == 0.21.0

DLPack == 0.6

## Usage
Execute:
```bash
bash run_example.sh
```
